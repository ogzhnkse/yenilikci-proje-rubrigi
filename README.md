# Yenilikçi Proje Rubriği

Yenilikçi proje sunumlarını jüri kriterlerine (Tanımlama, Tasarlama, Üretme, Sunum Süresi, İletişim ve Sunum Becerisi) göre puanlamak için tek sayfalık bir web uygulaması. Kayıtlar tarayıcıda (localStorage) saklanır ve CSV olarak dışa aktarılabilir.

GitHub Pages üzerinde yayınlanmıştır.
